# Desk Rocky

M5Stack **StackChan** (CoreS3, kit SKU **K151-R**) as the body. A Python brain on a laptop over Wi-Fi. Personality is **Rocky** from *Project Hail Mary*.

Owner: **Andrew Krowczyk**. License: MIT.

No Module LLM. The brain is a separate process. If the brain is unreachable, the body plays a scripted 12-second clip by itself.
